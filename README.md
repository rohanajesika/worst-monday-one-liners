A program that writes one funny line — a Monday where the deploy failed at 9:03, the inbox hit 4,000 unread, the stand-up ran 47 minutes, and the agent's context window filed for overtime — to `/output/entry.txt`. One sentence, 122 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Worst Monday One-Liners" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
